# 🎬 AI-Based Movie Recommendation System

A content-based movie recommendation system built with Python using the TMDB 5000 dataset. It recommends movies similar to a given title based on metadata like genres, cast, crew, and keywords.

---

## 🛠 Tech Stack
- Python
- Pandas & NumPy
- Scikit-learn
- TMDB 5000 Dataset

---

## 📂 Dataset
- tmdb_5000_movies.csv
- tmdb_5000_credits.csv

---

## 🚀 How to Run

1. Clone the repo
   git clone https://github.com/Priyanka-IT-cit/AI-BASED-MOVIE_RECOMENDATION.git

2. Create virtual environment
   python -m venv venv

3. Activate virtual environment
   venv\Scripts\activate

4. Install dependencies
   pip install pandas scikit-learn numpy

5. Run the app
   python app.py

---

## 📌 Features
- Content-based filtering
- TF-IDF Vectorization
- Cosine Similarity
- Recommends top similar movies

---

## 📊 How It Works
1. Loads TMDB 5000 movies and credits dataset
2. Merges and preprocesses the data
3. Applies TF-IDF Vectorization on movie metadata
4. Calculates Cosine Similarity between movies
5. Returns top recommended movies
